🛠️ Arquitetura & Procedência dos Dados

Um coletor em Python consulta a API pública do PNCP, aplicando os critérios da categoria oficial de TIC (CatSer) e busca semântica no objeto para contratações não catalogadas na origem. Os dados são consolidados no dataset estático e consumidos tanto pelo servidor MCP (para o Claude) quanto por esta página no navegador.

Classificação Legal: A separação entre renovações prováveis e novas licitações é uma triagem de prospecção apoiada no teto de 60 meses do art. 105 da Lei 14.133/2021 para serviços continuados de TIC.
