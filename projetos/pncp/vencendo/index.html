Como isto é montado

A API pública de consulta do PNCP (/v1/contratos) não filtra por UF, esfera nem vigência — só por órgão. A busca por trás do próprio site do PNCP (/api/search/) filtra as três coisas de verdade e devolve a data de vigência final direto no registro, então é essa que este levantamento usa: candidatos de TIC via busca textual (com frases entre aspas, para não virar palavra solta), esfera federal, UF Distrito Federal, filtrados pela vigência final caindo na janela de alerta.

Limite honesto: a classificação de TIC e de "serviço" é heurística de palavra-chave no objeto — serve para priorizar leitura, não como conclusão jurídica ou contábil. O objeto completo e o link para a página oficial do contrato no PNCP estão sempre disponíveis para conferência.
