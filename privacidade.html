Política de Privacidade

Última atualização: 2026-09-04

Coleta de dados

Este site não coleta dados pessoais de quem visita. Não há cookies, não há scripts de analytics, não há rastreadores de terceiros e não há formulários que capturem informação do visitante. É um site estático: HTML, CSS e JavaScript servidos diretamente, sem backend próprio processando requisições.

Hospedagem

O site é hospedado no GitHub Pages (GitHub, Inc.). A infraestrutura de hospedagem pode registrar logs técnicos padrão de acesso (IP, user-agent) por conta própria — isso é regido pela política de coleta de dados do GitHub Pages, fora do controle deste site.

Dados públicos exibidos

Os dashboards deste site (MCP-PNCP) exibem dados de contratações públicas obtidos da API oficial do PNCP (Portal Nacional de Contratações Públicas), públicos por força da Lei de Acesso à Informação. Não são dados pessoais de quem visita o site — são dados de contratos e órgãos públicos.

Contato voluntário

A única forma de contato é o link de e-mail no rodapé (mailto:) — se você enviar um e-mail, isso acontece diretamente no seu cliente de e-mail e este site não intermedia nem armazena essa troca.
