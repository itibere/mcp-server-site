Sobre este site

Quem mantém

Site pessoal de Itiberê Paquier, atuando com redes e segurança da informação. Este domínio hospeda projetos pessoais de engenharia de software e inteligência artificial aplicados a dados públicos brasileiros — sem fins comerciais, sem cadastro de usuários.

O que tem aqui

  • MCP-PNCP — monitor de contratações públicas de TIC coletadas via API pública do Portal Nacional de Contratações Públicas (PNCP), com um servidor MCP para consulta via Claude e outros assistentes de IA.
  • RAG-Licitações — busca semântica sobre normativos de contratação pública (Lei 14.133/2021, Lei 13.303/2016, Portaria SGD/MGI 1.070/2023).

Como é construído

Site 100% estático, hospedado no GitHub Pages, sem backend próprio, sem analytics, sem cookies e sem rastreamento de qualquer tipo — ver Política de Privacidade. Os dados exibidos vêm exclusivamente de fontes públicas oficiais (API do PNCP), amparados pela Lei de Acesso à Informação.
