API DE FERRAMENTAS

Ferramentas Expostas ao Claude (Tools)

Qualquer cliente compatível com MCP tem acesso imediato às seguintes funções do servidor:

Consulta as contratações públicas recentes, filtrando exclusivamente o catálogo de TIC e dispensas eletrônicas.

Parâmetros aceitos:
uf: string (ex: "DF", "SP", "BR")
dias: integer (default: 30, janela de busca)
termo: string opcional (ex: "firewall", "nuvem", "switch")
valor_minimo: float opcional (filtro por corte orçamentário)

Extrai o objeto detalhado, itens contratados, modalidade e histórico de prorrogações apoiado no art. 105 da Lei 14.133/2021.

Parâmetros aceitos:
numero_controle: string (identificador unívoco PNCP)
cnpj: string (CNPJ do órgão comprador)

Gera um panorama consolidado de volume financeiro, quantidade de dispensas e pregões realizados por um órgão específico.
